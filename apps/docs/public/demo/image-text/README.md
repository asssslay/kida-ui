# ImageText demo photograph

`pink-bloom.webp` is a 600 × 750 photograph by **Anthony Melone**:
<https://unsplash.com/photos/W6zVhDL_ijg>.

Used under the [Unsplash License](https://unsplash.com/license).
The licensed file is stored locally so the demo has no dependency on another animation
or an external image server. Its original WebP bytes are unchanged.

This is a website/playground demonstration asset, not an image bundled with the React component
or its copied source. Applications supply their own licensed photograph through `image`.
