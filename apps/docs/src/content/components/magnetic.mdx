## Usage

```tsx
import { Magnetic } from '@kida-ui/react'
import '@kida-ui/styles/kida.css'

<Magnetic>
  <button type="button">Come closer</button>
</Magnetic>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `strength` | `number` | `0.22` | Portion of pointer distance followed. |
| `maxDistance` | `number` | `18` | Maximum travel in CSS pixels. |
| `targetClassName` | `string` | — | Class applied to the isolated moving layer. |

The root also accepts span attributes, `className`, `style`, event handlers, and a forwarded `ref`.

### CSS custom properties

| Property | Default | Description |
| --- | --- | --- |
| `--kida-magnetic-activation-distance` | `2rem` | Stable pointer area around the stationary root. |

## Input and performance

Only mouse and pen movement activate the effect. Touch input is ignored, and the wrapped control
continues to own its click, focus, and keyboard behavior. Magnetic does not reveal information, so
no keyboard-only motion is required.

The root rectangle is cached on pointer entry and refreshed by `ResizeObserver`; pointer movement
does not trigger a layout read on every frame. A stable invisible pointer area lets the target react
before the pointer reaches it and prevents its own movement from ending the interaction. Updates
retarget one persistent spring at most once per animation frame, and listeners, observers, animation
frames, motion values, and spring subscriptions are removed on unmount.

## Reduced motion

The controller attaches no pointer behavior when reduced motion is requested. CSS also overrides an
animation already in flight if the preference changes while the component is mounted.
