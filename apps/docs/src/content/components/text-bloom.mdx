## Usage

```tsx
import { TextBloom } from '@kida-ui/react'
import '@kida-ui/styles/kida.css'

<TextBloom as="h1" voice="pop">
  Make the headline bloom.
</TextBloom>
```

Use word segmentation for most interface copy. Character segmentation is best reserved for short
display phrases, where its longer sequence will not delay comprehension.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `string` | required | The readable and animated text. |
| `by` | `'word' \| 'character'` | `'word'` | Segmentation unit. |
| `voice` | `'gentle' \| 'pop'` | `'gentle'` | Soft rise or small overshoot. |
| `stagger` | `number` | `0.045` | Seconds between segments. |
| `delay` | `number` | `0` | Seconds before the first segment. |
| `duration` | `number` | `0.55` | Seconds per segment. |
| `once` | `boolean` | `true` | Animate only on the first viewport entry. |
| `amount` | `'some' \| 'all' \| number` | `0.4` | Required visible portion. |
| `as` | `ElementType` | `'span'` | Semantic element to render. |

Safe native attributes, `className`, `style`, and a forwarded `ref` are passed to the root.

## Accessibility and reduced motion

The authored string remains the root's accessible label. Visual segments are hidden from assistive
technology, preventing screen readers from announcing one word or character at a time. The visual
text remains selectable and copyable.

Under reduced motion, every segment renders immediately at its settled position. The server output
uses deterministic segments and keys, so hydration does not change the text structure.
