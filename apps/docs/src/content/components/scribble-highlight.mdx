## API

### Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'underline' \| 'circle'` | `'underline'` | Shape drawn around the content. |
| `once` | `boolean` | `true` | Draw only on the first viewport entry. |
| `amount` | `'some' \| 'all' \| number` | `0.4` | Required visible portion. |

The root accepts span attributes, `className`, `style`, and a forwarded `ref`.

### CSS custom properties

| Property | Default | Description |
| --- | --- | --- |
| `--kida-scribble-color` | `#e94f86` | Stroke color. |
| `--kida-scribble-width` | `0.14em` | Stroke width. |
| `--kida-scribble-duration` | `650ms` | Draw duration. |

## Accessibility and input behavior

The SVG is decorative and hidden from assistive technology; the wrapped text remains ordinary,
readable content. Static paths avoid generated IDs and remain deterministic during server rendering.
Reduced motion displays the completed mark without running the draw animation.
