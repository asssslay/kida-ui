## Customization

</Demo>

Use word segmentation for most interface copy. Character segmentation is best reserved for short
display phrases, where its longer sequence will not delay comprehension.

Gentle uses a soft rise without a bounce. Pop starts smaller, rises into an 8% overshoot,
then briefly recoils before settling. Both use the same default duration and finish at the
text's natural size and position.

## API

### Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `text` | `string` | required | The readable and animated text. |
| `by` | `'word' \| 'character'` | `'word'` | Segmentation unit. |
| `voice` | `'gentle' \| 'pop'` | `'gentle'` | Soft rise or pronounced overshoot with a brief recoil. |
| `stagger` | `number` | `0.045` | Seconds between segments. |
| `delay` | `number` | `0` | Seconds before the first segment. |
| `duration` | `number` | `0.55` | Seconds per segment. |
| `once` | `boolean` | `true` | Animate only on the first viewport entry. |
| `amount` | `'some' \| 'all' \| number` | `0.4` | Required visible portion. |
| `as` | `keyof HTMLElementTagNameMap` | `'span'` | Semantic element to render. |
| `element` | `HTMLElement \| null` | `null` | Use `bind:element` to read the root DOM element. |

Safe native attributes, `class`, `style`, and event handlers are passed to the root.

## Accessibility and input behavior

The animated segments remain in authored order as one DOM text sequence, without replacing the
text with an ARIA label on a generic element. The same text is therefore available to assistive
technology, selection, and copy operations without a duplicated accessible copy.

Under reduced motion, every segment renders immediately at its settled position. The server output
uses deterministic segments and keys, so hydration does not change the text structure.

## Troubleshooting

> `text` must be a string so TextBloom can create deterministic, accessible segments. Wrap the
> component in a `{#key}` block to replay a one-time bloom that has already entered the viewport.
