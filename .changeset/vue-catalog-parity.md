Add Vue adapters for ImageText, SpaceType, GlowHighlight, and DualWave, completing Vue support for
the catalog. DualWave supports `v-model:index` and emits `index-change`; SpaceType emits
`geometry-change`; ImageText takes a `text` prop. Options update without restarting, with shared
cleanup, reduced-motion, SSR/hydration, React/Vue pixel parity, copied-source installation, and Vue
documentation demos.
